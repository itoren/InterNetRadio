# 📻 InterNetRadio

**InterNetRadio** — это современный, легкий и стильный веб-плеер для прослушивания интернет-радио прямо в браузере. Приложение создано для комфортного прослушивания музыки с фокусом на UX: поддержка горячих клавиш, умный таймер сна и понятная индикация статусов.

## ✨ Возможности

- 🎧 **Live-стриминг:** Воспроизведение радиостанций в реальном времени с индикацией статуса (Ожидание запуска / Воспроизведение).
- 📋 **Умный каталог:** Динамическая загрузка списка станций с обработкой состояний (загрузка, ошибки, отсутствие станций).
- 🌙 **Таймер сна (Sleep Timer):** Автоматическое отключение плеера через 15, 30 или 60 минут. Идеально, чтобы засыпать под любимую музыку.
- ⌨️ **Доступность и UX:** Управление воспроизведением (Play/Pause) с помощью клавиши `Пробел`.
- 🎨 **Неоновый интерфейс:** Минималистичный и современный дизайн.
- 🚨 **Обработка ошибок:** Информативные уведомления для пользователя при сбоях сети или проблемах с потоком.

## 🛠 Технологии
- **HTML5 / CSS3**
- **Vue.js**
- **HTML5 Audio API**
